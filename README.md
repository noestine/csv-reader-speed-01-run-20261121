A faster drop-in for csv-reader 1.0.0 — reads broken CSV files identically, about 5x faster. `solve.js` is a dependency-free ES module whose `run(input)` returns exactly csv-reader's answer for every case; `main.ts` reads `/input/cases.json`, answers each case with `run`, and writes `/output/answers.json`.
